# أثَر | ATHAR 🌱

منصة عربية تجريبية للناشئة والشباب: مسارات تقنية، تحديات، مبادرات مجتمعية، وقصص ملهمة.
«تقنية تُلهم، وقيمٌ تصنع الأثر» — «مستقبلك يبدأ بفكرة، وأثرك يبدأ بخطوة».

موقع ثابت (HTML + CSS + JS) بدون خادم خلفي. جميع البيانات تجريبية وتُحفظ في `localStorage` فقط.

## التشغيل محليًا

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8080
# ثم افتح http://localhost:8080
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا وارفع هذه الملفات إلى الفرع `main`.
2. من **Settings → Pages** اختر **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)`.
3. أو ادفع على `main` وسيعمل ملف `.github/workflows/deploy.yml` تلقائيًا.

> جميع المسارات نسبية (`./style.css` و `./app.js`) ليعمل الموقع سواء كان على النطاق الجذري أو داخل مستودع فرعي (`username.github.io/repo/`).
